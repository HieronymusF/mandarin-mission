> 任务等级：M

> 上位门禁：[`public-mvp-completion.md`](public-mvp-completion.md) 的 G1/G2

## 用户问题与本轮目标

本切片启动前，App 只有 Journey、课程和复习入口。用户无法稳定发现复习与设置，也无法在 App 内查看帮助、隐私/条款状态、本地数据控制或准确版本信息。

本轮交付一个可独立验收的“设置与信任中心”切片：

- 主导航提供 Journey、Review、Settings 三个稳定入口；课程播放页不显示主导航，避免干扰单任务流程；
- Settings 可以进入帮助、隐私、服务条款和数据管理页面，并显示运行安装包的版本号与构建号；
- 帮助、隐私和条款页面的本地说明可离线阅读；只有显式配置真实资源时才提供外部动作；
- 用户可以在二次确认后清除本机学习进度、掌握度、练习历史、口语历史和待同步事件，已安装的课程包不删除；
- 加载、失败、外部资源不可用、外链打开失败和数据清理提交状态都有可观察反馈。

## 假设与边界

- 首发界面继续使用英语；本轮不引入 i18n 框架。
- 产品负责人尚未提供真实支持邮箱、支持网页、隐私政策 URL、服务条款 URL 或法律主体。本轮只接收构建时显式配置，不提交假邮箱、假 URL 或冒充正式法律文本的占位页。
- 核心课程与本地说明不依赖网络。外链打开失败时保留当前页面并提示检查连接或稍后重试。
- 本轮不实现账号、同步、通知、分析/崩溃选择、订阅、购买、线上工单或账号删除；这些仍由公开 MVP 后续切片负责。
- 最简单可行方案是复用现有 `go_router`、Riverpod、shadcn、Lucide、Drift 和项目布局组件；不新增导航框架、网络探测、远端配置或第二套 UI 库。

## 配置契约

以下 `dart-define` 只有在值通过校验时才产生可点击动作：

| Key | 用途 | 允许值 |
|---|---|---|
| `MM_SUPPORT_EMAIL` | 联系支持 | 非空邮箱地址 |
| `MM_SUPPORT_URL` | 支持网页 | `https` URL |
| `MM_PRIVACY_URL` | 正式隐私政策 | `https` URL |
| `MM_TERMS_URL` | 正式服务条款 | `https` URL |

缺失或无效值统一显示“尚未配置”，不能生成死链接。运行版本通过平台包信息读取，不在页面代码中硬编码。

## 页面与状态

| 页面/动作 | 正常 | 加载/提交中 | 失败或不可用 |
|---|---|---|---|
| 主导航 | 三个入口可发现，当前入口有选中状态 | 不适用 | 本地导航不依赖网络 |
| Settings 版本信息 | 显示版本号与构建号 | 显示加载状态 | 显示重试且不影响其他设置入口 |
| 帮助/隐私/条款 | 本地说明始终可读；有真实配置时可打开外部资源 | 打开期间禁用重复点击 | 未配置时说明缺少生产资源；打开失败时显示连接/重试提示 |
| 数据管理 | 说明清除范围和保留范围 | 确认后禁用重复提交 | 失败时不声称已清除并提供重试；成功后显示可验证结果 |

## 验收标准

1. 从 Journey 可通过主导航进入 Review 与 Settings，再返回 Journey；课程页不显示主导航。
2. Settings 的帮助、隐私、条款、数据管理入口均能到达真实页面；返回关系一致。
3. 包信息加载成功、加载中、失败与重试均有 Widget 测试。
4. 无真实配置时不存在可点击的支持、隐私或条款外链；有效配置使用系统外部应用打开，返回 `false` 或抛错时显示失败提示。
5. 清除本机数据必须先显示影响范围和二次确认；取消不改数据库，确认后清空五类学习数据与 Outbox，保留已安装课程包，并刷新 Journey/Review 派生状态。
6. 关键动作有语义标签和至少 `44 × 44` 触控目标；360 逻辑像素宽、200% 字号无溢出或被遮挡。
7. 移动端 format、analyze、test、Debug APK 与 `git diff --check` 通过；UI 自动证据与真机视觉验收分开报告。

## 实现证据（2026-07-27）

- `app/router.dart` 与 `main_navigation_shell.dart` 提供 Journey、Review、Settings 主导航，课程路由保持独立；
- `features/settings/` 提供 Settings、帮助、隐私、条款、数据管理页面，以及包信息、外链和清除本地学习数据的状态边界；
- 未配置 `MM_SUPPORT_EMAIL`、`MM_SUPPORT_URL`、`MM_PRIVACY_URL`、`MM_TERMS_URL` 时只显示未配置状态，不生成外部动作；
- 78 个 Flutter 测试、format、analyze、Debug APK 与 `git diff --check` 通过；Android 模拟器已核对 Settings 主页面、三项主导航语义和实际 `Version 0.2.0 (3)`；用户标注后的列表标题 18px/600、辅助文字 14px/400 与共同左边线由 Widget 几何断言和同视口截图共同验证；
- 本轮没有连接 Sony 真机，也没有取得真实支持/法律资源，因此 G1/G2 仍不能判定通过。

## 隐私、Schema 与回滚

- 本轮不收集或上传新数据，不记录邮箱、Token、录音、转写或购买票据。
- 不修改 Drift Schema；清理动作只删除现有学习者数据表记录，保留内容包表。
- 外链和包信息通过可替换 Service 边界接入，Widget 测试不调用平台插件。
- 回滚可移除 Settings Feature、主导航 Shell 和两项插件依赖；现有 Journey、课程、复习数据结构不需要迁移。
