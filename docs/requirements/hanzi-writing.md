# 汉字书写练习需求

## 用户问题与目标

当前课程在展示汉字、拼音和读音后直接进入听辨与口语，用户只能认读，不能把字形主动写出来。中文没有字母式“拼写”；本功能把该需求实现为简单汉字书写练习。

完成后，用户在学会“咖啡”的读法后，会依次：

1. 在田字格和浅色字模上用手指临摹；
2. 隐藏字模，在空白田字格中凭记忆书写；
3. 显示标准字形，对照自己的书写并选择自评；
4. 将 `hanzi` 维度结果立即保存到本地。

## 当前切片

- 新增课程步骤类型 `hanzi_trace`；
- “点咖啡”课程在“咖啡”教学卡之后插入一个书写步骤；
- 支持多字词，首个内容为“咖啡”；
- 画布支持手指或鼠标书写、清空和重新练习；
- 临摹和脱稿书写都必须产生笔迹后才能进入下一阶段；
- 最终自评为 `Needs practice` 或 `Looks close`；
- 保存失败时保留当前书写与自评，允许重试；
- 整个流程不依赖网络。

## 状态

| 状态 | 字模 | 用户操作 | 继续条件 |
|---|---|---|---|
| 临摹 | 显示浅色汉字 | 临摹、清空 | 至少产生一笔 |
| 默写 | 隐藏汉字 | 凭记忆书写、清空 | 至少产生一笔 |
| 对照 | 显示标准字形和用户笔迹 | 自评或重新练习 | 已选择自评 |
| 保存中 | 保持对照结果 | 禁止重复提交 | 本地事务完成 |
| 保存失败 | 保持对照结果和自评 | 重试保存 | 保存成功 |

## 数据与契约

- 内容来源：安装包内课程 JSON；
- `CourseLessonStep.type = hanzi_trace`；
- `itemId` 指向已有 `KnowledgeItem`，直接复用 `hanzi`、`pinyinSyllables` 和 `english`；
- 自评通过 `LessonProgressRepository.recordExerciseAttempt` 写入：
  - `dimension = hanzi`；
  - `Looks close` → `remembered / correct = true`；
  - `Needs practice` → `forgotten / correct = false`；
  - 同一事务更新掌握度、写入 `ReviewAttempts` 和 Outbox；
- 不新增数据库表，不需要 migration，不保存原始手写轨迹。

## 无障碍与响应式

- 画布提供明确语义标签，按钮不能只依赖图标；
- 画布不是完成课程的唯一输入方式：无法使用绘图手势时，可使用“Skip drawing”进入自评，并按使用提示保存；
- 360 × 800、200% 字号下可滚动完成，不溢出；
- 宽屏继续使用现有内容最大宽度。

## 验收标准

1. 内容 Schema 和 validator 接受 `hanzi_trace`，且 `itemId` 必须存在；
2. “点咖啡”课程从读法教学进入“Write 咖啡”；
3. 临摹阶段未书写时不能进入默写；
4. 默写阶段未书写时不能进入对照；
5. 对照后选择自评才能保存并进入下一课步；
6. 保存结果真实写入 `ReviewAttempts`、`MasteryStates` 和 Outbox；
7. 保存失败不清除轨迹或自评；
8. 跳过绘图时记录 `usedHint = true`；
9. Widget、端到端、内容校验、200% 字号与 Android 视觉验收通过。

## 明确不做

- 高精度字形相似度评分；
- 自动判断笔画、笔顺、起收笔或书写美观度；
- 保存、上传或同步原始手写轨迹；
- 外部手写识别 SDK；
- 未经授权的逐笔动画或字体资产；
- 把书写单独扩展成第五个复习维度；一期继续归入 `hanzi`。
