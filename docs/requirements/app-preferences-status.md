# App 偏好与服务状态

> 状态：基础状态页已由 PR #25 合并；本地选择控制扩展位于 `agent/privacy-controls`，尚未提交、推送或运行远端 CI
> 日期：2026-07-27

## 用户问题与目标

当前 Settings 已能查看帮助、隐私、条款、本地数据和版本，但用户无法在一个明确入口确认界面语言、课程语言、音频/麦克风边界，以及通知、诊断、账号和同步是否真的启用。

“App preferences”先以离线只读状态页交付；当前扩展在同一页加入通知与可选诊断的本地选择。选择只约束当前 App 是否可以在未来能力接入后启用这些可选服务，不冒充通知已经投递或诊断数据已经发送。

## 主路径与状态

1. 用户从 Settings 打开 App preferences。
2. 页面展示：
   - 界面语言为 English，当前不能切换；
   - 学习内容为 Simplified Chinese，并提供拼音和英文引导；
   - 已下载课程音频可离线播放；
   - 麦克风仅在用户开始口语录音时请求，拒绝后仍可自评继续；
   - 通知投递、分析/崩溃服务、账号与同步尚未接入；
   - 通知与分析/崩溃选择默认关闭，可独立开启或撤回。
3. 开关先写入本机版本化偏好，写入成功后才改变页面状态；失败时保留之前的选择并说明未保存。
4. 重新打开 App 后选择仍然存在；用户可返回 Settings，页面不依赖网络、账号或外部配置。

本机偏好读取期间显示加载状态；读取失败时不猜测当前值，提供重试。账号与同步继续显示不可用状态。

## 数据与隐私边界

- 两个选择分别保存在 `preferences.notifications.enabled.v1` 与 `preferences.diagnostics.enabled.v1`，默认值均为 `false`；不为布尔偏好修改 Drift Schema。
- 不新增远端 API、通知/分析/崩溃 SDK、系统权限或后台任务。
- 打开页面不会请求麦克风、通知或跟踪权限。
- 不上传学习数据、录音、诊断信息或设备标识。

## 验收标准

- Settings 中存在可发现的 App preferences 入口。
- 页面逐项显示语言、学习内容、音频、麦克风、通知、分析/崩溃和账号/同步状态。
- 通知与分析/崩溃选择默认关闭，可以开启、跨 App 进程恢复并再次关闭。
- 页面始终说明服务尚未接入；开关打开不能被表述成已投递通知或已发送诊断数据。
- 读取失败提供重试；写入失败保留之前的选择并显示明确错误。
- 返回关系正确；在 360×800、200% 文字缩放下可滚动且无溢出。
- 两个开关具有开/关语义与至少 44×44dp 可点击区域。
- 现有 Settings、课程和主导航测试继续通过。

## 明确不做

- 不实现语言切换、通知调度或投递、分析或崩溃 SDK、账号登录或云同步。
- 不请求新的系统权限。
- 不据此把 G1/G2 标记为完成；真实支持渠道、正式政策、通知/诊断服务接入、逐版本数据清单与账号能力仍是后续门禁。
