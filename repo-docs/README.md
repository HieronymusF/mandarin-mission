# Mandarin Mission 仓库导览

Mandarin Mission 是一款面向英语使用者的零基础普通话学习 App。当前仓库已经能用一份版本化课程数据驱动“点咖啡”课程，把答题、课程完成和四维掌握度保存到本地，再在到期时生成复习队列。

最值得先建立的模型是“本地学习闭环”：内容包决定教什么，Flutter App 决定当前呈现什么，纯 Dart 规则决定何时复习，Drift 负责把结果和待同步事件一起落盘。网络和媒体能力失败时，课程仍保留可完成路径。

当前边界也很明确：三条基于 Apache-2.0 Kokoro 模型生成的 TTS 音频已作为开发占位打包，用户认为“能用但不满意”，后续可能替换为许可清晰的商用 TTS；Sony 真机已通过播放、授权、普通/永久拒绝、设置返回恢复、录音、回放、重录、Home 和步骤返回清理，也完成课程、冷启动进度保留、到期复习与飞行模式完整课程。真实来电因设备无 SIM 尚未完成。Go API 只有健康、就绪和版本端点，尚未参与课程、账号或同步流程。

## 仓库当前能做什么

- 从 Journey 打开 `cafe-01`，按内容数据渲染八个课程步骤。
- 保存听力、汉字和口语自评；完成时建立三个知识点的四维掌握度。
- 按 0—5 箱规则查询到期项目，完成本地复习并支持保存失败重试。
- 在课程音频或录音能力不可用时显示明确降级，不阻断课程。
- 用三个 CI job 分别验证 Flutter App、纯 Dart 规则与内容、Go API 容器。

计划中但尚未完成的范围包括最终课程音色选择与普通话审核、Android 真机服务不可用和来电生命周期验收、Go 业务 API、云同步、账号和订阅。开发前应先读项目根目录的 `HANDOFF.md`，它保存的是实时状态；本导览只保存稳定且可从仓库复核的理解。
