# Mandarin Mission 仓库导览

Mandarin Mission 是一款面向英语使用者的零基础普通话学习 App。当前默认正式课程包覆盖 Café、Market、Metro 3 个地点、12 节课和 3 个地点终局；它把答题、课程完成和四维掌握度保存到本地，再在到期时生成复习队列。

最值得先建立的模型是“本地学习闭环”：内容包决定教什么，Flutter App 决定当前呈现什么，纯 Dart 规则决定何时复习，Drift 负责把结果和待同步事件一起落盘。网络和媒体能力失败时，课程仍保留可完成路径。

当前边界也很明确：M2 的 53 个资产均已具备可播放文件，49 条新增普通话音频与新增范围 14/14 单元已通过既定审核和 Sony 真机验收；内容包已成为 App 默认加载的正式内容。GitHub 上的 0.2.0+3 Pre-release 验收包已在 Sony `XQ-DQ72` 覆盖安装并冷启动，真实 Journey 精确展示 Café、Market、Metro 各 4 节课和 1 个地点终局。生产 App 现有首次使用门禁、Journey/Review/Settings 主导航、偏好与服务状态、帮助/隐私/条款状态页、本地数据清理和版本信息；偏好页会明确说明通知、分析/崩溃、账号和同步尚未接入，而不会提供无效开关。真实支持/法律资源、这些服务的真实控制、删除账号和订阅仍未完成；Go API 也只有健康、就绪和版本端点。因此它仍不是公开 MVP 或商店候选，正式签名和商店提交不是当前优先级。

## 仓库当前能做什么

- 从 Journey 按线性先修关系打开 12 节课程，并在每个地点四课后进入独立终局。
- 保存听力、汉字和口语自评；完成时建立三个知识点的四维掌握度。
- 按 0—5 箱规则查询到期项目，完成本地复习并支持保存失败重试。
- 在课程音频或录音能力不可用时显示明确降级，不阻断课程。
- 首次启动先说明学习方式、离线和本地数据边界；完成后进入 Journey，后续启动不再打扰，并可从 Settings 重看。
- 从稳定主导航进入 Review 和 Settings；离线查看帮助/隐私/条款状态，并在二次确认后清除本机学习数据而保留课程包。
- 在 App preferences 查看当前界面/内容语言、离线音频与可选麦克风边界，并区分未接入的通知、诊断和账号同步。
- 用三个 CI job 分别验证 Flutter App、纯 Dart 规则与内容、Go API 容器。

计划中但尚未完成的范围包括真实客服/法律资源、通知与可选收集的真实控制、Go 业务 API、账号/同步/删除、订阅、分析/崩溃、完整每日任务/连胜/印章、6 个地点/约 30 节内容，以及公开 MVP 的跨平台质量验收。商店签名和提交排在这些能力全部完成之后。开发前应先读项目根目录的 `HANDOFF.md`，它保存的是实时状态；本导览只保存稳定且可从仓库复核的理解。
